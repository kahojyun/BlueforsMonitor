# 交互验收

以下清单用于桌面实机验收，核心回归通过不代表全部 UI 项目自动通过。

- 首次启动无数据，仅提供 Logfiles 入口，默认跟随系统。
- 选择目录后完成索引；重启恢复目录；空目录持续等待新增日志。
- 追加完整行更新读数与事件；半行等待补全。
- 勾选跟随最新推进视野；取消后仍采集但不改变当前范围。
- 时间平移和缩放不重置手动纵轴；各通道纵轴独立。
- 隐藏通道释放轴空间，全部隐藏不崩溃。
- 日期应用、事件单击高亮、双击回看；事件选择不覆盖手填日期。
- 全历史视图保留极值，光标读数仍查询原始记录，超过 90 秒显示无记录。
- 深浅和系统主题切换；PNG 导出；事件带显示开关。
- 单轴/多轴切换，选中纵轴适配。

与 Python 的剩余交互差异：没有图内可拖动通道标签（改为拖动纵轴），事件表高度固定。Windows 启动和打开 Logfiles 已由用户实机验证；实时环境、跨午夜和长时间运行仍待验证。

## 实时环境待验收

- 跟随开启时追加记录后视野前进。
- 跟随关闭时仍采集，手动纵轴与时间范围保持。
- 跨午夜发现新目录，关闭重开无重复或遗漏。
