## 编译绑定、主题与日期输入

- 状态、数据源及事件数量改用 C# 编译绑定；桌面回归检查属性通知后的实际控件内容。
- 文本、事件类型、恢复状态、曲线、事件带和光标统一使用 UiTheme 语义颜色。已检查明暗切换及继承应用主题时的同步更新。
- 日期区间独立布局，时间控件使用默认模板尺寸，不覆盖 Fluent 内部宽度资源。检查最小窗口宽度 1280 下的布局，并以 192 DPI 渲染检查明暗界面；这不代替 Windows 实机高 DPI 验证。
- 空日期、非法日期、空时间、相同及倒置区间均显示输入区错误，保持视野和跟随状态；修正后应用会清除提示并暂停跟随。日历解析错误时清除旧日期，防止静默回退后应用旧值。
- 桌面回归需要图形桌面；CI 继续在三个平台执行构建、核心回归及依赖声明校验。

## 主窗口控件拆分

事件列表、日期范围和通道面板已抽为独立控件。Mac 桌面回归覆盖控件初始化无反向通知、日期应用仅触发一次导航、列表选择不跳转、双击回看、刷新保留选择、通道全隐藏与恢复、单/多轴切换及设置保存，并继续运行主题、日期错误、布局及日志跟随检查。明暗模式在最小窗口宽度下重新渲染检查。Windows 图形交互仍需实机验收，三平台 CI 验证构建及核心回归。

## TableView 事件表

事件表改用 Avalonia 内置 TableView，保留七列、主题语义色、详情提示、选择高亮、双击回看及刷新选择恢复。表头拖动可调整列宽，当前窗口刷新不会重置宽度；重启后恢复默认比例，暂不保存列宽到设置。

Mac 桌面回归新增列分隔线 DragDelta 路由测试，验证拖动后表头与单元格位置/宽度一致；表头及分隔线双击不触发回看，数据行双击仍触发一次。明暗模式最小窗口布局已检查。未新增排序、筛选或单元格复制功能。

## 紧凑布局与专注模式

- Mac 桌面回归：默认收起日期、通道与读数合并、事件展开/收起、分隔条拖动保存、详情开关、专注进入/退出及新窗口恢复均通过；布局切换保留时间范围、跟随状态和手动纵轴范围。

## 监测会话与坐标轴拆分

- MonitoringSession 核心回归使用可控任务验证查询乱序、过期异常、revision 变化、切换数据源后的显示/光标隔离、光标桶复用和关闭取消；使用临时真实日志验证空目录后新增记录、无变化刷新及打开失败保留当前源。
- AxisController 独立检查覆盖 CH6 单位换算、排列、拖动平移、锚点缩放、手动范围保留、单轴恢复自动、选中轴适配、时间范围下限及隐藏轴退出布局。
- Mac 桌面回归重新覆盖日期、主题、事件表、隐藏轴释放宽度、暂停/跟随追加日志、紧凑/专注模式、布局保存及小窗口。三平台 CI 执行核心会话检查；坐标轴和 GUI 检查在 Mac 图形桌面运行，Windows 实机实时环境仍待验收。

缓存命中也会取消上一视野的在途查询：回归按“已加载 A → 请求 B → 返回缓存 A → B 迟到完成”的确定顺序验证，B 不得替换 A。界面接受缓存结果后同步恢复状态文本，避免停留在“正在读取”。
