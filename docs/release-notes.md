## 窗口适配与记忆

- 启动时按屏幕可用区域和缩放比例调整窗口，预留标题栏和边框空间，避免小屏幕上窗口超出屏幕。
- 记住退出前的窗口大小、位置和最大化状态；最大化不会覆盖普通窗口的尺寸。
- 换屏幕或调整缩放后，恢复的位置会校正到当前屏幕内。
- 可用空间过小时提供滚动条，仍可访问日期、事件及底部操作。

从 0.6.0 升级可继续使用现有索引和设置，无需重新索引。首次启动使用适应当前屏幕的默认大小，调整后退出即可记住。
